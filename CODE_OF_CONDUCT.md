# DreamBound Community Conduct

DreamBound Adventures is a child-focused DPN Technology project. Repository collaboration should stay professional, constructive and safe.

## Expected

- Be respectful and specific.
- Critique code and ideas, not people.
- Protect private information.
- Keep child-safety concerns high priority.
- Report vulnerabilities responsibly.
- Use age-appropriate language in player-facing content.
- Provide evidence for technical claims.

## Not acceptable

- Harassment, threats or discriminatory abuse.
- Sexualized or otherwise inappropriate content involving minors.
- Posting child private information.
- Publishing credentials or weaponized exploits.
- Deliberately bypassing repository security controls.
- Misrepresenting mockups as shipped game functionality.

Project maintainers may edit, hide, lock or remove contributions that violate these expectations.

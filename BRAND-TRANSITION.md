# DreamBound Adventures — Brand Transition

**New game name:** DreamBound Adventures  
**Previous working title:** WonderWorld Adventures  
**Rebrand build:** v0.4.1

## Save compatibility

DreamBound uses new `dreambound-profile-*` browser save keys. On first launch, the game automatically checks for older `wonderworld-profile-*` saves, copies them into the DreamBound namespace, and leaves the original legacy saves untouched as a fallback.

## Updated player-facing terminology

- WonderWorld → DreamBound
- WonderBuddy → DreamBuddy
- WonderCreatures → DreamCreatures
- Wonder Stars → Dream Stars
- Wonder Collection → Dream Collection
- Wonder Home → Dream Home
- Wonder Machine → Dream Machine
- WonderWish → DreamWish

Gameplay, quests, collections, and existing v0.4 progress remain compatible.

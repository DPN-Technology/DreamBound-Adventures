# Odyssey Kindness Network

Design target for the next DreamBound milestone: connect autonomous NPC routines, friendship progression, cooperative badges, and gentle world-state feedback into the Odyssey Network. The system remains local-only, has no public scoring, no timers or punishment loops, and preserves DreamShield controls.

## Acceptance goals

- Reward helping Nova, Gear, and Moss without competitive ranking.
- Surface local friendship and routine discoveries as optional progression.
- Keep persisted values bounded and sanitized before use.
- No remote APIs, analytics, public chat, external child-facing links, or account dependency.
- Respect reduced-motion, large-UI, and existing accessibility settings.
- Integrate through modular vNext events rather than expanding legacy game.js.

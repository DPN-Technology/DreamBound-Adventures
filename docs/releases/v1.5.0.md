# DreamBound Adventures v1.5.0 — Living World Expedition

DreamBound Adventures v1.5.0 is the first official GitHub release of the unified Living World runtime.

## Highlights

- One unified DreamBound game and progression system
- Six connected DreamGate realms
- DreamPulse adaptive engagement objectives
- DreamTrials with Star Sense, Luma Link, and Maker Spark
- Cinematic non-combat Guardian Encounters
- Kinetic traversal routes and ability-gated world movement
- Connected expedition interiors:
  - Moonflower Vault
  - Maker Core
  - Ocean Observatory
- Moving teamwork relays with Luma and NPC support
- Moving-platform Motion Chains with safe-reset environmental hazards
- Persistent room restoration, traversal mastery, discoveries, friendship, and Odyssey XP
- Local-only child-safe gameplay with no public chat, accounts, analytics, ads, or remote content
